Real Estate Price Prediction

Project Visuals

Problem

Problem

Price estimates were inconsistent across regions and failed to capture local market behaviors. Analysts were spending too much time manually correcting outliers before client delivery.

Workflow

Approach

  • Engineered spatial features from neighborhood, transit, school, and amenity signals.
  • Compared random forest, gradient boosting, and stacked ensembles.
  • Used geospatial clustering to improve local calibration and reduce outlier drift.
  • Published valuation API and broker-facing dashboard.
Architecture

Architecture and Workflow

  1. Raw listing and transaction data are normalized into canonical schema.
  2. Geospatial joins enrich each property with neighborhood signals.
  3. Ensemble model predicts valuation with confidence intervals.
  4. API powers broker dashboard and batch valuation exports.
Challenges

Challenges and Fixes

Challenge: unstable predictions in low-volume neighborhoods

Fix: introduced micro-market clustering and Bayesian smoothing.

Challenge: data lag from listing vendors

Fix: added freshness checks and fallback interpolation pipeline.

Stack

Tech Stack

Scikit-learn GeoPandas XGBoost Streamlit Docker

Results

  • Mean absolute error reduced by 18%.
  • Regional estimate stability improved across 12 markets.
  • Analyst manual adjustment workload cut by 45%.
