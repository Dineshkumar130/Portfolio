Fraud Detection System

Built a real-time fraud scoring platform for digital payments that reduced false positives while preserving high recall.

Problem

Problem

The fraud team was reviewing too many low-quality alerts and missing high-risk edge cases during peak payment windows. Existing rules were hard to tune and created frequent friction for legitimate customers.

Workflow

Approach

  • Unified transaction, device, and user-behavior features in a feature store.
  • Trained XGBoost with class-weighting and calibrated probability thresholds.
  • Deployed low-latency scoring API behind Kafka-driven event ingestion.
  • Added human feedback loop for weekly retraining and drift monitoring.
Architecture

Architecture and Workflow

  1. Incoming payments stream into Kafka topics with enrichment metadata.
  2. Real-time feature lookup merges account behavior and device signatures.
  3. Scoring service returns probability + risk level in under 120ms.
  4. High-risk events route to analyst queue and trigger action workflows.
Challenges

Challenges and Fixes

Challenge: high false-positive rate on new users

Fix: introduced cohort-specific thresholds and cold-start features.

Challenge: model drift during promotion campaigns

Fix: added campaign-aware features and weekly retraining cadence.

Stack

Tech Stack

Python XGBoost Kafka PostgreSQL Docker

Results

  • False-positive rate dropped by 40%.
  • Recall improved from 0.81 to 0.89.
  • Analyst review time reduced by 32%.
